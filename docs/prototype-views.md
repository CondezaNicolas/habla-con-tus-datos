# Vistas de producto / Demo

- **Modo:** Operate.
- **Rutas:** `/demo`, `/demo/analysis`, `/demo/sql` y `/demo/states`.
- **Usuario y trabajo:** una persona carga un archivo, entiende qué se detectó, formula una pregunta y revisa la respuesta junto al SQL que la respalda.
- **Acciones actuales:** el conjunto de ejemplo permite recorrer carga → análisis → SQL; las acciones que requieren API aparecen deshabilitadas de forma explícita.
- **Estados cubiertos:** preparación del archivo, archivo inválido, sesión temporal expirada y límite temporal de la demo.
- **Dirección:** las superficies operativas heredan el zine técnico en tinta, papel y color de evidencia, pero se comportan como un producto familiar: jerarquía de datos, navegación consistente, tablas legibles y feedback claro.
- **Pendiente de backend:** sustituir datos de muestra por respuestas FastAPI/DuckDB; habilitar archivo, preguntas, copiar SQL y exportación de resultados.
