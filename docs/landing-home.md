# Landing / Home

- **Modo:** Persuade.
- **Audiencia:** potenciales usuarios de la demo y clientes freelance que evalúan el portafolio.
- **Trabajo:** entender rápidamente la promesa y avanzar hacia la demostración sin registro.
- **Acción principal:** explorar el ejemplo de producto; el enlace queda anclado al demo mientras la funcionalidad real se construye.
- **Prueba disponible:** mock de interfaz con datos explícitamente ilustrativos; SQL visible como mecanismo de confianza. No hay testimonios, clientes ni métricas inventadas.
- **Dirección:** zine técnico explicador. El flujo archivo → pregunta → SQL → gráfico es el artefacto dominante. Tinta, papel, teal, coral y amarillo operan como lenguaje editorial, no como decoración.
- **Momento memorable:** la ventana de producto aparece al mismo nivel que la declaración de valor y muestra una respuesta respaldada por SQL ejecutable.
- **Pendiente:** conectar la CTA y el mock a la demo FastAPI/DuckDB real en la fase de producto.
